# new

A Russian-language landing page for СТО Гараж, an auto repair shop in Simferopol.

The page presents the shop’s services, including suspension repair, driveshaft repair, and vehicle maintenance. It provides the shop’s address at 3 Elevatorny Lane, Simferopol. The site is built with TanStack Start and TypeScript.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://simferopol-garage-masters.lovable.app
